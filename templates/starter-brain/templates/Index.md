# Templates

Note templates for Obsidian's core Templates plugin (Settings > Core plugins >
Templates, then set the template folder to this one). This folder is excluded
from search so placeholders are never quoted as evidence.

Daily, Project, Decision, Person and Meeting templates share the same
frontmatter keys: `aliases`, `related`, `supersedes`, `status`, `tags`.

Five more keep long work resumable across sessions and agents (see
docs/working-records.md in the Paracortex repository):

- Memory: one fact, preference or standing decision per note, listed one line
  each in a memory index.
- Handover: a dated running log, so the next session can resume.
- Directive Log: the owner's decisions word for word, dated and numbered.
- Claim Ledger: one claim per row with its evidence status.
- Board: the plan, written and agreed before the work starts.

They use the same frontmatter keys.
